# Локальный музыкальный Telegram-бот

Python 3.10 или новее. Дополнительные пакеты не нужны.

## Запуск в Windows

1. Скопируйте `.env.example` в `.env` и замените `PASTE_TOKEN_HERE` токеном из @BotFather. Ранее опубликованный токен лучше перевыпустить через `/revoke`.
2. В @BotFather отправьте `/setinline`, выберите своего бота и укажите подсказку `Найти музыку`. Код не может включить этот режим за вас.
3. Откройте `start.bat` двойным щелчком либо выполните `python bot.py` из этой папки.
4. Откройте бота в Telegram, нажмите «Старт» и отправьте MP3/M4A как **музыку с аудиоплеером**, а не как документ. Можно переслать существующее аудиосообщение с музыкой.
5. Бот скачает трек в папку, загрузит обратно с названием и проверит пригодность для inline. После ответа «Сохранено в папку и проверено» в любом чате введите `@имя_бота исполнитель` и выберите трек. После имени бота нужен пробел. Пустой запрос показывает последние треки.

Для исходного бота пример: `@pechkinlog_bot название`.

Окно программы должно оставаться открытым, компьютер — включённым и подключённым к интернету. Остановка: Ctrl+C. Одновременно запускайте только один экземпляр для одного токена. При ошибке 409 остановите другой экземпляр.

## Возможности

Музыка хранится в `music/library_<bot_id>/<user_id>/` рядом с программой. Имена файлов — устойчивые идентификаторы; названия и исполнители находятся в SQLite. Не переименовывайте файлы внутри этой папки. База старой версии обновляется автоматически.

`/cache` скачивает существующую библиотеку в папку без отправки музыки обратно. `/repair` загружает треки из папки в Telegram с явным названием и проверяет их для inline. Если локальной копии ещё нет, бот сначала скачает её. При восстановлении треки придут вам обратно. При сбое загрузки локальная копия остаётся, повторный `/repair` использует её. Для скачивания через обычный Telegram Bot API поддерживаются файлы до 20 МБ; требуется интернет.

Inline использует Telegram file_id подготовленного аудио. Прямое чтение локальной папки из inline-выдачи Telegram не поддерживает. Проблемный трек не скрывает исправные; если все результаты требуют восстановления, отображается подсказка.

- Приём аудио в личных сообщениях, включая пересланные треки.
- Поиск без учёта регистра по названию, исполнителю, имени файла и подписи. Поддерживается русский язык; несколько слов ищутся вместе.
- Общая библиотека: любой пользователь может отправить музыку боту в личный чат. Все пользователи ищут среди всех загруженных треков. Одинаковые аудио в общей выдаче не дублируются. Ранее загруженные треки тоже доступны всем.
- Поиск: `@pechkinlog_bot название исполнитель` в любом чате или `/search название исполнитель` в личном чате. Пустой inline-запрос показывает последние треки, запрос со словами фильтрует выдачу.
- `/library` — последние 20 общих треков, `/cache` — скачать свои треки, `/repair` — загрузить свои треки из папки, `/help` — помощь. Команды восстановления обрабатывают только загрузки отправителя.
- Повторная загрузка того же аудио обновляет запись без дубля.
- База `library_<bot_id>.sqlite3` и папка `music` сохраняются после перезапуска. Для резервной копии сохраняйте обе. Автоматический импорт произвольных файлов, положенных вручную в папку, не реализован: добавляйте музыку через личный чат с ботом.

Музыка появляется в чужом чате только после вашего выбора в inline-выдаче. Поиск не обращается к внешним музыкальным сервисам.

## Проверка

`python -m unittest -v` проверяет сохранение, общий поиск из другого аккаунта, устранение дублей, ограничение восстановления своими треками, пагинацию и формирование inline-ответов без обращения к Telegram.

API: https://core.telegram.org/bots/api#inlinequeryresultcachedaudio
